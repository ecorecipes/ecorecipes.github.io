    Installing a package

    Most ecorecipes packages are not yet in Julia's General registry, so install them straight from GitHub. Every card above has a Copy install button that puts the right command on your clipboard.

    Packages in the same family depend on one another. If the package manager cannot find a dependency, add the family's foundation package the same way first.

    Julia REPL
    using Pkg
Pkg.add(url="https://github.com/ecorecipes/MatrixProjectionModels.jl")

using MatrixProjectionModels
